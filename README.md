# MAROCAINTY 🇲🇦
**Marketplace e-commerce dédiée exclusivement aux marques locales marocaines.** [cite: 3, 4]

## 🌟 Vision du Projet
MAROCAINTY est une plateforme digitale qui regroupe uniquement des marques locales et des startups marocaines. [cite: 6] [cite_start]L'objectif est de valoriser l'économie locale et de garantir l'authenticité des produits issus du patrimoine marocain. [cite: 28, 39]

## 🎯 Fonctionnalités Clés (À développer)
**Catalogue 100% Local:** Uniquement des produits sans transformation étrangère. [cite: 25, 28]
**Pages Marques:** Chaque artisan ou startup aura son espace personnalisé avec sa présentation et ses contacts. [cite: 13, 20]
**Parcours Client:** Navigation par catégories, consultation de fiches produits et achat en ligne. [cite: 32, 33, 34]

## 🛠️ Stack Technique
- **Frontend:** HTML5, CSS3, JavaScript (React à venir).
- **Hébergement:** GitHub Pages / Vercel.
